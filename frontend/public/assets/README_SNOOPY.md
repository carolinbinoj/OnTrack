# Snoopy Logo Asset Placement

As specified in the implementation brief:
Place your supplied Snoopy image asset (e.g. `snoopy_logo.png` or `snoopy_logo.jpg`) directly in this folder:
`frontend/public/assets/snoopy_logo.png`

The Productivity Hub sidebar automatically looks for:
`/assets/snoopy_logo.png`
If not yet supplied, it gracefully renders the built-in illustrated Snoopy badge with its transparent warm container.
